## 重要：应用图标里的文字是 `Ctrl2cmd`

设计定稿图标（天蓝底 + 白色文字）里的文字是 **Ctrl2cmd**，共 8 个字符：

| 索引 | 字符 | x 范围（1024 基准） |
|---|---|---|
| 0 | C | 264–328 |
| 1 | t | 334–369 |
| 2 | r | 377–411 |
| 3 | l | 421–439 |
| 4 | 2 | 457–525 |
| 5 | c | 540–604 |
| 6 | m | 614–693 |
| 7 | d | 703–756 |

（以上为文字区 x 264–756、y 475–551 内的相对坐标。）

**容易出错的地方**：用列扫描自动切分字符时，缝隙阈值很关键 ——
`l` 与 `2` 之间、`K` 字形内部的斜臂都会被误判。若阈值过大会把多个字母并成一段
（曾在阈值 8px 时把 C/t/r/l 合并），过小则把单个字母拆开。
调试时务必把每段单独渲染出来核对，不要只看包围盒数字。

## 字体特征（自绘 WK 时参照）

从原图测得：

- 笔画宽度：**19px**（在 1024 画布上）
- 大写字母高：**72px**，x-height：**53px**
- 笔画为圆头收笔
- `m` 的三根竖笔间距：12px

## 菜单栏图标（WK）的来源

菜单栏图标从 **`WK.icns`** 提取：该文件是 1024 画布上的天蓝 squircle，
白色 WK 字形位于 x 268–753、y 414–610（485×196，宽高比 2.47:1）。

提取方式：取亮度 >170 的白色像素，按亮度换算 alpha 做成**模板图**
（纯黑 + 只用 alpha），系统会按菜单栏明暗自动着色。

    python3 tools/extract_wk_menubar.py

> 早期版本是用 `tools/draw_wk_icon.py` 自绘的 WK（原图里没有 W 和 K）。
> 现已改用设计者提供的真字形，自绘脚本保留备查。
